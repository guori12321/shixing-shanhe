# 诗意影院制作记录

三首约一分钟的动态绘本朗诵影片：

- 望庐山瀑布：60秒，四景：晨光紫烟、遥望挂川、飞瀑千尺、银河九天。
- 春望：62秒，四景：山河草木、春花鸟鸣、烽火家书、白头牵挂。
- 念奴娇·赤壁怀古：66秒，四景：大江千古、乱石惊涛、周瑜想象、江月回望。

## 媒体与来源

- 原作均为古代公版作品，采用网站现有全文。片首导入、片尾提问为本项目编写。
- 画面通过内置 image_gen 生成，提示词保存在 image-prompts.json，源分镜保存在三个 *-storyboard.png。图像按四景制作镜头推移、溶接、雾气、落花、飞瀑或水面动态；属于动态绘本，不是完整角色逐帧表演。
- 普通话朗诵现由 zh-CN-YunxiNeural 神经语音生成，保持原生速率、不做时间拉伸，配乐在发声时进一步降低；个别古典多音字在朗诵输入中用同音字消歧，画面字幕保持原文。
- 配乐由 render_films.py 原创合成，使用五声音阶拨弦、长音与低鼓，不使用第三方录音。环境声同样由程序生成。
- 古代建筑、人物与景观为诗意艺术复现，不是考古复原。周瑜画面为词中历史想象；黄州赤壁不指通常认定的赤壁之战古战场。

## 输出

网站及下载文件在 ../dist/assets/films/：三段 MP4（H.264 / AAC，1280×720，24fps）、封面图、WEBVTT字幕和场景/朗诵时间清单。

## 再生成

1. 使用 macOS `say`：运行 prepare_films.py（需要本机语音服务访问）。
2. 使用 NumPy、Pillow、ffmpeg：运行 render_films.py。最多并行两片，逐帧编码，不把整段视频装入内存。
3. 运行 verify_films.py 核对时长、流格式、解码、字幕时间及四段动态画面。
4. work/ 为忽略的中间音频与预览缓存。timing.json 记录可复核的时间安排。

## 已检查

- 三片时长分别为60.000、62.000、66.000秒；均包含H.264画面和双声道AAC音频。
- 完整解码通过；四个场景均输出连续变化的视频帧；所有字幕时间在片长内。
- 朗诵字幕逐句拼接后，与网站对应三首诗词的全文一致（忽略标点和空白）。
- 影院三入口、作品关联、播放器弹窗及地图详情入口经逻辑检查。

## 自然语音修订

安装 edge-tts 7.3.1 后运行 neural_voice.py，再使用项目 NumPy/Pillow 运行环境运行 remix_neural.py。后者保留画面，按原有字幕起点替换声轨，重新混音为 48kHz AAC。natural-timing.json 保存实际语音时长；原 timing.json 保留画面制作安排。

## GitHub 发布副本

`films.json`、`timing.json` 和 `natural-timing.json` 中的音频路径已改为相对此目录的路径。`work/` 不随仓库分发；已编码影片位于 `../dist/assets/films/`，可直接运行网站。

需要重建当前自然语音声轨时，先安装 `requirements.txt` 中的依赖并确保 ffmpeg / ffprobe 在 PATH 中，再运行 `python neural_voice.py` 和 `python remix_neural.py`。这会使用已有时间安排生成新的网络合成语音，并替换已有影片的音轨。

完整重绘还需要 macOS Tingting（初始制作流程）、NumPy / Pillow、ffmpeg，以及脚本指定的宋体与黑体字体；其他系统需修改字体路径。
