# 诗意创作坊：课堂交互演示

入口：`studio.html`。地图站点和全文赏读均有带篇目参数的入口，例如 `studio.html?work=lb-lushan`。所有页面共用导航，创作坊与地图、书架、影院相互独立。

## 本次范围

按用户选择，本次**不连接任何付费或免费生成模型**。没有 API Key 输入框、服务端请求代理或真实生成任务。图片与影片复用本站已有的三组素材；仿写采用三个预写范例，可以由学生编辑。页面、作品卡和导出文件均注明演示性质。

- 215篇／组作品可作为提示词的阅读起点。
- 《望庐山瀑布》《春望》《念奴娇·赤壁怀古》有专门的场景、情感、文本证据与史实边界提示。
- 其他篇目按其原文、系年、位置类型和赏读重点构造提示词；参考素材会明确注明对应的是哪一篇，避免把样例误当作本次创作输出。
- 图片、约一分钟视频和四句仿写三种构思方式，每种提供三个可编辑示例方向。选择风格或视角不会直接覆盖学生已编辑的文字；点击示例可重新填入。
- 视频模式显示内置参考影片和四段概念分镜；分镜时间为构思参考，不声称逐帧对应既有影片。
- 每台浏览器初始20点**演示 Token**，图片预览2点、视频参考6点、仿写范例1点；可恢复。它是交互积分，不是语言模型计费单位，不是安全的生产配额系统。

## 学习与交流

保存作品卡需要填写诗句依据和个人想象说明。卡片保留篇目、提示词、学生编辑后的仿写、标题、化名和反馈。

作品、演示额度与反馈保存在当前浏览器的 localStorage，最多30张卡。尚未接入班级共享数据库，不会自动公开投稿或通知同学。课堂范例清楚标注，不冒充真实学生作品。

导出 JSON 作品卡后，可由同学自行导入，在本机留下有文本依据的反馈，再导出返回。导出文件包含构思与内置素材引用，不包含新生成的图片或视频。导入不改变额度，不执行文件内代码，不加载文件指定的外部资源；正文以转义文本呈现。

每次导入最多30张，文件上限2MB；篇目和作品类型必须在本站允许范围内。整个导入批次先验证再写入，避免无效条目导致部分导入。浏览器无法持久保存时会提示导出备份。

## 20分钟课堂用法

1. 读诗找依据（4分钟）：圈出两处意象与关键词。
2. 写提示词（5分钟）：明确表达形式、情感及想象边界。
3. 看例并修改（5分钟）：讨论提示词是否具体，修改仿写。
4. 同伴交流（6分钟）：交换作品卡，引用诗句提问，再回到原文修订。

评价关注文本依据、意象与情感的联系、史实和想象的区分，以及个人表达，不以画面华丽程度为主。教师引导位于页面底部。

## 验证

`node tests/studio.test.cjs`：类型白名单、未知篇目、输入长度、文本转义、批次原子性、导入额度隔离、本机卡片数量上限。

浏览器检查：三种预览、额度不足与恢复、作品保存、反馈保存、原诗联动、共享导航和重新加载后本机作品保留。
