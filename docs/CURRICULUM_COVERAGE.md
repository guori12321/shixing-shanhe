# 初高中古诗文收录与课标覆盖

核对日期：2026-10-22。当前收录215篇／组，其中37篇保留三位重点诗人的地图专题，新增178篇／组阅读文本。阅读库与地图分开；新增作者没有虚构坐标、行程或创作年份。

## 范围

完整覆盖以下附录的132条古诗文背诵推荐条目：初中60条；高中72条，包括文言文32条（必修10、选择性必修10、选修12），诗词曲40条。组合篇目按课标一条统计，例如《孟子》三则、古代文论六组选段。这些条目与215个阅读记录不是同一计数口径。

课标推荐目录不是所有考试题库。各省市、教材版本、考试年份，以及课外鉴赏、陌生文言文阅读可能超出目录。本站专收古诗文，没有将现代版权诗歌复制入库。教材补充是辅助阅读，未声称已经逐省核定所有考试范围。

## 目录依据

- [义务教育语文课标（2022年版2025年修订）](https://fxzx.qpedu.cn/jhzx/kcjs/kcbz/511663.htm)：附录1，印刷页61—63，PDF64—66；核对扫描原页。
- [普通高中语文课标（2017年版2025年修订）](https://scmlzx.cn/news/202511/497838942620618752.html)：附录1，印刷页57—61，PDF60—64。

不能直接套用旧汇编：初中《孟子》三则是鱼我所欲也、得道多助、生于忧患；《吕氏春秋》为伯牙鼓琴，不能替换为《列子》旧段；高中《逍遥游》选五石之瓠段。已补《归去来兮辞》《琵琶行》序文；《老子》八章与教材四章分开；《项脊轩志》保留通行本文自评段，实际教材可能删节。

## 文本整理与许可

古典原作属于公有领域。机器可读整理参考 [汤圆的初中古诗文库](https://github.com/tangyuan0821/Junior-Middle-School-poetry) 与 [Clover Yan 的高中整理](https://github.com/clover-tree/gaokao-poetry)，依CC BY-SA 4.0署名与共享。补充篇目仅提取 [hantang/yuwen](https://github.com/hantang/yuwen) 中古典正文，去掉教材注释和学习提示；孔雀东南飞参考维基文库公版古籍本；其他来源与修改见每篇文本和 [attribution.json](../dist/assets/catalog/attribution.json)。未复制现代译文或赏析。古籍异文、标点与教材差异，以实际教材为准。

大学公开汇编只用作古文原文参照，不用作现行目录证据。机器语料把李煜《相见欢》误配为朱敦儒“金陵城上西楼”，已恢复“无言独上西楼”正文并加入回归检查。校正了参考稿重复的《上枢密韩太尉书》、老子第十五章的缺文、题画／人间词话的明显录入错误。未采用其中错误标为齐桓晋文之事的段落。

## 可复核数据

- `data/curriculum-manifest.json`：132条目录及课程类别。
- `data/curriculum-coverage.json`：目录与网页阅读ID一一对应。
- `data/textbook-supplements.json`：14篇高中教材补充正文及来源。
- `dist/catalog-data.js`：构建后的阅读数据；网页无需下载原始语料。

重建需在缓存目录提供junior.json、high.json、high-reference.txt（大学PDF提取文本）、featured.json（现有37篇的ID、题名、作者与正文），运行 `python3 scripts/build_curriculum_catalog.py /path/to/cache`。原始来源与输入SHA256存于署名文件，来源变更后应重新逐条核对，不能按数量自动宣布覆盖。验证：`node tests/catalog.test.cjs` 和 `node tests/studio.test.cjs`。
