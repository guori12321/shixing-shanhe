# 地区接入

首发默认上海，状态为“首发参考版”。目前**尚无经逐项核定的上海中考／普通高考年度篇目清单**，不把全国目录改名为“上海考试范围”。默认显示全国课标背诵篇目和三位重点诗人的完整37篇专题，共150篇／组；勾选补充可查看全部215篇／组。全国课标视图默认显示215篇。

江苏、浙江、北京、广东仅为待接入规划，选项禁用，不会产生伪造的地区筛选结果。地区选择在浏览器本地保存，四个页面共享导航提示；地图仍专注三位诗人的足迹。

## 已查证的依据

- [上海市教委：初中学业水平考试实施办法](https://edu.sh.gov.cn/xxgk2_zdgz_rxgkyzs/20230412/ec0b8612c5c14970ad0260593696af43.html)：考试内容限定在课程标准规定范围内，并未提供具体年度的逐篇清单。
- [上海市教育考试院：2026春考语文试卷评析](https://www.shmeea.edu.cn/page/02300/20260104/19981.html)：综合阅读、诗歌鉴赏等考查超出背诵目录这一种学习形式。不能据此推导完整背诵篇目名单。
- 全国目录来源见 [课标覆盖说明](CURRICULUM_COVERAGE.md)。核对日期：2026-10-22。

## 后续接入要求

每个地区需分别核对初中／高中、考试年份、教材版本、官方篇目依据与指定选段；用作品稳定ID建立地区关系，区分背诵要求、教材学习和拓展阅读，保留来源与核对日期。完成后才启用地区选项及“本地区重点”标记。不得将三校生升学或合格性考试的清单误用于普通高考。

配置与交互：`dist/regions.js`；回归检查：`node tests/regions.test.cjs`。
