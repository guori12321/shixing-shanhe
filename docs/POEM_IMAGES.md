# 逐篇配图与替换指南

2026-10-22首轮：215篇／组全部各配2幅，共430个配图位置，复用30份实景照片、古画及意象图像。图片不是逐篇独占素材，也没有声称所有图片都是同一地点的实景。优先保留可核实的地域对应；缺少当地照片时明确标注意象参考或山水比较。

## 展示位置

- 地图当前作品：默认显示“照片与古画”，原有三段朗诵影片仍可切换查看，点击后播放。
- 书架卡片：第一幅图为封面，点击进入图片查看器。
- 原文赏读：并列展示两幅图及说明；可查看完整构图、前后切换、返回原文。
- 边塞诗背景阅读、创作坊“全文与赏读”：复用相同配图与署名。

地图与书架仍突出李白、杜甫、苏轼。图片不增加作者的行迹、地点或年份。

## 编辑哪个文件

`data/poem-image-map.json` 按作品ID配置图片。替换只影响该篇；不要改作品ID。

```json
{
  "ss-xihu": {
    "status": "首轮配图",
    "images": [
      {
        "asset": "xihu",
        "relation": "地域参考",
        "note": "杭州西湖的现代实景，作为地域对照；不是苏轼当年原貌。"
      },
      {
        "asset": "westlake-painting",
        "relation": "古画参照",
        "note": "李嵩画的是南宋西湖，不是苏轼北宋时的现场记录。"
      }
    ]
  }
}
```

`data/poem-image-assets.json` 管理素材本身：本地路径、中文标题、类型、作者、拍摄日期／画作年代、许可及原始来源。可以添加第三幅、第四幅，也可以删除某幅；目前构建检查要求每篇至少2幅。共有素材可跨作品复用，但每篇的对应关系与说明独立。

新增或替换步骤：

1. 将有授权的图片放入 `dist/assets/poem-images/`，用新的文件名和素材ID，保留原文件以便回退。
2. 在素材清单中填写作者、许可、来源，古画注明年代；不要把上传日期当作拍摄日期。
3. 修改目标作品的 `asset`、`relation`、`note`。属于区域、意象、纪念地或异地比较时明确说明，不能默认为写作现场。
4. 运行 `node scripts/build_poem_images.cjs` 和 `node tests/poem-images.test.cjs`，检查本地页面，再随网站一起发布。该脚本只编译清单，不重新自动分配图片，不会覆盖逐篇人工修订。

前端读取构建文件 `dist/poem-images-data.js`，由 `dist/poem-images.js` 统一渲染。不需修改地图、书架或创作坊的代码来替换图片。

## 来源与署名

新图像均来自Wikimedia Commons的开放照片与公版古画；机器可读原始元数据和下载来源见 `dist/assets/poem-images/credits.json`。原有5幅景区照片的记录保留在 `dist/assets/photos/credits.json`。每幅分别遵循其CC BY、CC BY-SA、公有领域等条件，不能按本站其他文件的许可统一处理。复制或再次编辑素材时应保留作者与许可，按相应条款再分发。

网页卡片会裁切预览，完整图像在查看器中保留构图。没有使用生成图片冒充现场照片。古画也没有被当作对应唐宋年份的建筑、河岸、战争的直接记录。

已检查的特殊对应：

- 黄鹤楼：现代重建建筑；非唐代原楼。
- 草堂：纪念性复建；《蜀相》中的图片明确不是武侯祠。
- 黄州赤壁：地区参考；不等于通常认定的赤壁之战古战场，也不是承天寺或定慧院的照片。
- 天姥山、石钟山暂用异地山水比较，逐图明确没有把参考图认作该地。
- 密州：今诸城村落银杏，非苏轼作词地点或出猎现场。
- 梅花、荷花：部分实拍来自日本或澳大利亚植物园，只作植物意象参考。
- 月面：NASA/JPL伽利略号1992年多滤镜增强色影像，只作月亮意象参考，不是当地月夜实拍。

## 本轮验证

构建检查覆盖215个阅读ID、每篇至少2个不同素材、所有本地文件存在、每幅有署名和许可。人工看过素材缩略总览，剔除地图、隧道、博物馆恐龙展等检索误匹配；在浏览器检查照片／古画放大切换、返回原文、书架封面、地图媒体切换与创作坊赏读。
